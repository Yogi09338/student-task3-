# Employee Salary Analysis

## Day 3 - AI & ML Internship

This project analyzes employee salary data using Python.

## Objective

To practice numerical data processing using Python.

## Salary Data

The program uses a list of employee salaries and calculates:

- Total salary
- Average salary
- Highest salary
- Lowest salary

## Results

- Total Salary: 311000
- Average Salary: 38875.0
- Highest Salary: 52000
- Lowest Salary: 25000

## Tools Used

- Python
- Jupyter Notebook

## Python Functions Used

- sum()
- len()
- max()
- min()
